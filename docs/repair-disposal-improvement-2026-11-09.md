# 修理と車を手放す相談の改善

実施日: 2026-11-09

## ユーザー確認済みの事実

- 新規の板金塗装見積りと受注が増えており、事前の電話なしで来店する方も多い。HPが起点か、どの記事が決め手かは未確認。
- 修理可能な部位は板金修理を検討し、交換が必要な場合も中古部品を探し、きれいに整えて使うなど、費用を抑える方法を提案している。
- 古い車・事故車についても、車両や資源等の評価から手配・手続き等の費用を考慮し、お渡しできる金額があるか相談できる。必ず正の金額になるという保証ではない。

## 変更した範囲

- 板金塗装の既存ページと費用記事を強化。検索タイトル・URLは維持し、確認済みの修理方針を具体化した。未確認のデントリペア・部分補修・リビルト対応などは、自社サービスとして足さない。
- 修理ページの見出しは語の途中で割れないよう個別に調整。既存のカード装飾は、セクション追加で適用先がずれないよう対象IDで指定する。
- `/column/old-car-disposal-cost/` を新設。処分費用を払う前に、買取評価、必要な費用、差し引き後の金額、引渡し先・手続きを確認する案内にした。
- 「有料処分は悪質」「産廃業者ならどこでも引取可能」「どんな車も無料」「必ず買取」「解体・引取の自社登録あり」といった未確認・一律の主張はしない。
- 安全に来店できる車は実車相談へ、動かない車・事故後の車は無理に自走せず電話で引取の可否・費用を確認する案内へ分けた。
- トップFAQ、板金塗装FAQ、費用記事、コラムのテーマ別案内・全記事一覧から新記事へつなぐ。既存の主要記事リンクと並びを維持する。
- トップとコラム一覧の静的な紹介を「直近30日人気トップ3」と呼ぶ表記は、実際の自動集計ではないため修正。
- 地図リンクを修理ページ・トップ会社案内・会社ページ・新記事へ追加。住所を含むGoogle Maps検索URLを使用し、APIキー・位置情報取得・新しい外部SDKは追加しない。
- 中古車ページ、その在庫表示順、検索タイトル、仕入れ相談記事は変更しない。0〜3台の初期表示の回帰検証を維持する。

## 計測と比較

- `directions_click` を追加。サイトから店舗地図を開いた行動で、ルート検索や来店完了ではない。個人情報・現在地・入力住所はイベントに追加しない。
- 電話は既存の `phone_prompt_open` / `phone_dial` を利用。実際の受注と区別し、電話ゼロでも来店ゼロとは扱わない。
- 受付で聞けた認知経路と決め手を任意に記録する。聞けなかった場合は不明のまま残す。個人情報をGA4・Clarityへ送信しない。
- 2026-10-12〜2026-11-08に修理・保険関連ページから始まったGA4セッションは29、前の28日（2026-09-14〜2026-10-11）は13。保険記事には地域外・情報収集目的も含まれ得る。来店・受注増の原因を証明する数字ではない。
- 公開後28日程度を確保し、修理記事の検索表示・クリック、修理ページの電話・地図操作、新しい処分相談記事の流入を別々に見る。自動監視タスクは新設していない。
